# AGENTS.md

Instructions for AI coding agents working on piShop are kept in one place, in
plain Markdown that any assistant can read:

- [`CLAUDE.md`](CLAUDE.md): what piShop is, the repository map, commands, and
  the rules every change follows. **Read it first.**
- [`.claude/skills/add-community-game/SKILL.md`](.claude/skills/add-community-game/SKILL.md):
  step by step for adding or updating a game in the Community tab (`community/`).
- [`.claude/skills/pishop-feature/SKILL.md`](.claude/skills/pishop-feature/SKILL.md):
  step by step for building or changing a feature in the app (`launcher/`, `web/`).

Load the guide that matches the task before starting it. Humans: see
[CONTRIBUTING.md](CONTRIBUTING.md).
